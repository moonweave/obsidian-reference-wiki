# Security policy

## Supported versions

Security fixes are made on the latest tagged release and the current `main`
branch. Older prereleases and versions previously released under MIT are not
maintained.

## Report a vulnerability

Use GitHub's private **Report a vulnerability** form in the repository Security
tab. Do not open a public issue for a vulnerability.

Include the affected version or commit, operating system, minimal reproduction,
expected impact, and whether a real Vault or source file was involved. Never
attach private PDFs, extracted full text, API keys, cookies, personal Vault
paths, or other confidential research material. Use a synthetic fixture when
possible.

Moonweave will acknowledge and triage reports on a best-effort basis. Please do
not publish exploit details before a fix or mitigation is available.
